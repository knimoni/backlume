# Questoria Design System

## 1. Design Direction

Questoria is a personal game library and quest tracking application.

The visual style should feel:

- Clean
- Calm
- Precise
- Gaming-oriented
- Practical
- Personal

Questoria should feel like a real application rather than a gaming landing page.

Avoid overly futuristic, flashy, or "AI-generated" visual styles.

---

## 2. Visual References

Primary references:

- Linear — minimal, precise, structured interface
- PlayStation — subtle gaming identity and strong use of game imagery

Component foundation:

- shadcn/ui

Styling:

- Tailwind CSS

---

## 3. Color Direction

### Background

Use a soft neutral background rather than pure white.

- Background: #F7F7F5
- Surface: #FFFFFF
- Border: #E5E5E5

### Text

- Primary: #171717
- Secondary: #737373
- Muted: #A3A3A3

### Accent

Use a restrained blue/cyan accent.

The accent should support interaction and navigation,
not dominate the interface.

Avoid neon colors.

---

## 4. Typography

Use a clean sans-serif typeface.

Typography should prioritize:

- Readability
- Clear hierarchy
- Moderate font weights
- Compact headings

Avoid oversized hero typography.

---

## 5. Layout

Use a medium-density application layout.

Prefer:

- Clear spacing
- Consistent alignment
- Moderate content width
- Simple navigation
- Game covers as visual anchors

Avoid excessive empty space.

Avoid excessive cards.

---

## 6. Components

Components should have:

- Small to medium border radius
- Subtle borders
- Minimal shadows
- Clear hover states
- Simple interaction feedback

Avoid:

- Excessive rounded corners
- Heavy shadows
- Glassmorphism
- Excessive gradients
- Neon glow
- Unnecessary animations

---

## 7. Game Library

The library is one of the primary features of Questoria.

Game covers should provide the main visual identity.

Prefer a clean list or compact grid depending on the page.

Game information should remain easy to scan:

- Game title
- Playtime
- Status
- Rating
- Progress

---

## 8. Status

Game status should be visually distinguishable without relying only on color.

Statuses:

- Backlog
- Playing
- Completed
- Dropped

Use subtle badges and clear text.

---

## 9. Interaction

Interactions should feel responsive but restrained.

Use animation only when it improves clarity.

Examples:

- Button hover
- Navigation state
- Modal transition
- Success feedback

Avoid decorative animation.

---

## 10. Do

- Keep interfaces simple
- Use game artwork intentionally
- Maintain consistent spacing
- Use one primary accent
- Prioritize readability
- Keep gaming elements subtle
- Make important actions obvious

---

## 11. Don't

- Don't use excessive gradients
- Don't use neon gamer aesthetics
- Don't use excessive glassmorphism
- Don't make every element a card
- Don't overuse rounded corners
- Don't add animation without purpose
- Don't make the UI look like a landing page
- Don't make the interface feel AI-generated
